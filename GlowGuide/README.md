# GlowGuide AI

GlowGuide AI is an AI-powered skincare assistant that provides personalized skincare recommendations based on skin characteristics, concerns, and environmental factors.

## Features

- Skin type prediction
- Personalized skincare routine
- Product recommendations
- AI-powered analysis
- User-friendly web interface

## Tech Stack

- Python
- Flask
- Scikit-learn
- TensorFlow (optional)
- Pandas
- NumPy
- HTML/CSS
- JavaScript

## Installation

```bash
git clone https://github.com/yourusername/glowguide-ai.git
cd glowguide-ai
pip install -r requirements.txt
python app.py
